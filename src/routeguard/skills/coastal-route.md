# 沿海路线技能

1. 沿海骑行必须显式给出沿海城市作为途经点，否则路由会选内陆最短路径；
2. 中国东海岸常用链条：上海—宁波—台州—温州—宁德—福州—莆田—泉州—厦门—汕头；
3. 如果用户只给了起终点却说"沿海"，先用 `geocode` 解析这两端，
   再在 `final` 里给出建议途经点，并说明"要沿海请用 --via 指定"；
4. 沿海路线爬升通常 8–10 m/km，明显高于此值说明走了内陆山区。
